# 💰 Expense Tracker Web Application

A simple and user-friendly **Expense Tracker Web Application** built using **Python (Flask)** as the backend and **HTML, CSS** for the frontend.  
This application helps users record daily expenses, categorize them, and track spending efficiently.

---

## 📌 Project Description

Managing daily expenses manually is time-consuming and error-prone.  
This Expense Tracker provides a digital solution to **add, view, and analyze expenses** in an organized manner. The application stores expense data securely and displays it in a clean and interactive interface.

This project demonstrates practical implementation of **Flask, database management, and frontend integration**, making it suitable for beginners as well as academic submissions.

---

## 🎯 Objectives

- To record daily expenses efficiently  
- To categorize expenses (Food, Travel, Shopping, etc.)
- To display expense history in a structured format  
- To calculate total expenses based on categories  
- To provide a simple and intuitive user interface  

---

## ⚙️ Technologies Used

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS  
- **Database:** SQLite  
- **Tools:** VS Code, GitHub  

---

## 🧠 Features

- Add new expenses with date, category, and amount  
- View all recorded expenses  
- Calculate total expenses by category  
- Simple and responsive UI  
- Lightweight and easy to use
